# tapat_ai
TAPAT is a hyper-local, privacy-first mobile application that bridges the physical world with offline artificial intelligence. By combining NFC (Near Field Communication) triggers, RAG (Retrieval-Augmented Generation), and a fully local LLM (Large Language Model), TAPAT delivers instant, context-aware answers grounded strictly in your personal data—entirely on-device and offline. The name TAPAT stems from a clever Tagalog double entendre: it represents the physical action of bringing a device directly in front of an NFC tag (tapat), while guaranteeing an honest, hallucinations-free answer (tapat) rooted solely in your verified data.
